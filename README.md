# 💻 Exercícios de Programação em C

Este repositório foi criado para armazenar os meus códigos e exercícios desenvolvidos durante a disciplina.

## 📁 Arquivos Incluídos

* `Adivinha.c` - Jogo de adivinhação.
* `Exercicio1Conceitos.cpp` - Exercício focado em conceitos iniciais.
* `Exercicio2Terreno.cpp` - Cálculo de dimensões e área de terreno.
* `Exercicio3pesoideal.cpp` - Cálculo de peso ideal.
* `Filtrodevalores.c` - Filtragem e validação de valores.
* `Tabuada.c` - Geração de tabuada.
* `pente.c` - Algoritmo de ordenação (Pencort / Pente).
* `contadorDePares.c` - Contagem de números pares.
* `exer1soma.c` - Exercício básico de soma.
* `mediaemaioridade.c` - Verificação de média e maioridade.
* `sexo3.c` - Estrutura condicional para classificação de gênero/sexo.
* `soma1.c` - Programa de soma simples.
* `somador.c` - Acumulador/somador de valores.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C / C++
* **Ferramenta de Estudo:** GitHub e Dev-C++ / Code::Blocks / VS Code

## 🚀 Como Executar os Programas

1. Faça o download ou abra o arquivo desejado.
2. Abra o arquivo em um compilador compatível (como Dev-C++, Code::Blocks ou VS Code).
3. Compile e execute para ver o resultado na tela!
